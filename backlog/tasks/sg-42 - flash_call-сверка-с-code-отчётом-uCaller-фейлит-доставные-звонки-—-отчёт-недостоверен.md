## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Причина перемерена 08.10 контрольными прогонами v121/v122 (улики: HANDOFF-sg42.md в корне репо, закоммичен владельцем): отчёт code uCaller — честное эхо запрошенного кода. Ложный «different digits» рождался в нашем _settle сверкой с уже стёртым кодом: check_verification пишет code=NULL при терминале, человек подтверждает за секунды, вендор отчитывается до минуты — добор всегда приходил позже подтверждения и сверялся с пустотой. Все 6 боевых рунг с причиной different digits — этот артефакт (каждый на подтверждённой верификации); 8 без расхождения истекли неподтверждёнными (код ещё жил — свера честная). Исходная премиса задачи «отчёт недостоверен» опровергнута этими же прогонами. Симптом чинился в двух версиях: первая (commit 2c66749) глушила сверу целиком по ложной премисе — откачена; финальная чинит саму сверку.
<!-- SECTION:DESCRIPTION:END -->
