Слова владельца 26.09.2026: «Экран настроек сделан для гика. Хуже этого только env-файлы править в консоли». Сейчас это одна таблица из 59 настроек по SETTINGS_SPEC: ключ-идентификатор, английская подсказка, true/false в select, пять настроек сырым JSON в textarea. Бэкенд-валидаторы (validate_raw, check_every_account_is_rate_bound) не менять без нужды: формы собирают тот же JSON. Ветка feature/settings-screen, хендофф .claude/handoff/settings-screen.md.
